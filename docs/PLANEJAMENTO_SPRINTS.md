## Trabalho colaborativo

Os responsáveis acima lideram cada entrega, mas toda a equipe pode auxiliar em implementação, documentação, revisões e testes. Mudanças de código devem ocorrer em branches próprias, com Pull Requests revisados antes de qualquer merge para a `main`.
