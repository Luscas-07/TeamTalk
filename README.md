# TeamTalk

Aplicação de comunicação interna e colaboração corporativa, desenvolvida como projeto acadêmico A3.

## Tecnologias

- Next.js 15 com App Router
- React 19
- TypeScript
- ESLint

## Requisitos

- Node.js 20.9 ou superior
- npm

## Como executar

1. Instale as dependências com `npm install`.
2. Inicie o ambiente de desenvolvimento com `npm run dev`.
3. Abra `http://localhost:3000` no navegador.

## Estrutura inicial

```text
src/
  app/
    globals.css
    layout.tsx
    page.tsx
```

A tela atual é apenas uma base visual demonstrativa. Autenticação, persistência e mensagens em tempo real serão integradas em etapas posteriores.

## Contribuição

- Trabalhe em uma branch própria vinculada a uma issue.
- Não envie alterações diretamente para `main`.
- Abra um Pull Request para revisão antes de integrar alterações.
- Nunca inclua chaves, senhas ou outros segredos no código.
